# Preview review checklist

Report each item as pass / fail with a one-line reason. Don't edit files.

## Facts
- [ ] Every finding is still true on the live site today (open it and check).
- [ ] Business name, phone, address and hours in the mockup match the live site.
- [ ] No invented claims, prices, awards or reviews in the mockup.

## Brand
- [ ] Page chrome uses Chambers branding; the mockup uses the client's brand only.

## Privacy
- [ ] URL uses the token, not the slug.
- [ ] Page is `noindex`, absent from the sitemap, and `/preview/` is disallowed in robots.txt.

## Quality
- [ ] Slider works with mouse, touch and keyboard; Desktop/Phone toggle works.
- [ ] Before/after images are the same width and crop.
- [ ] Alt text present. Mockup body text contrast ≥ 4.5:1.
- [ ] Findings read as plain English, one sentence each, 3–5 total.
- [ ] Page passes typecheck, lint and tests.

Verdict: send / fix first.
